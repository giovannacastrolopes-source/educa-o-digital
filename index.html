Primeiros Passos com HTML e CSS

Até agora, a página apresentava apenas textos. A partir deste momento, inserimos elementos visuais e controlamos os espaçamentos internos (padding) e externos (margin) para deixar a leitura muito mais confortável.

Com o Box Model (conteúdo, padding, borda e margem), o layout do site responde automaticamente quando a tela do navegador é redimensionada, mantendo tudo centralizado e elegante.
